PORTFOLIO RAJA — #SWAG EDITORIAL

Cara menjalankan:
1. Extract folder ZIP.
2. Buka index.html dengan browser.
3. Jangan pisahkan folder assets dari index.html/style.css/script.js.

File utama:
- index.html  : struktur website
- style.css   : seluruh desain responsive desktop + HP
- script.js   : loader, menu HP, modal sertifikat, invert mode, animasi/cursor
- assets/     : 1 foto hero + 6 sertifikat

Catatan:
- Tombol SAY HELLO mengarah ke WhatsApp. Tombol EMAIL ME mengarah ke Gmail.
- Nomor WhatsApp menggunakan format internasional wa.me (62 tanpa angka 0 di depan).
- Website memakai Google Fonts saat internet tersedia. Jika offline, otomatis memakai font sistem.
- Tampilan terinspirasi gaya editorial/experimental #SWAG, bukan salinan 1:1 dari referensi.
